## 1. 시스템 개요

**인사톡 노무톡**은 노무법인이 여러 고객사의 근로계약, 급여, 연차, 퇴직급여, 4대보험 등을 통합 관리하고, 고객사 사장님께서 직접 급여명세서와 통계를 조회할 수 있는 **양방향 웹 플랫폼**입니다.

### 사용자 구분

| 구분 | 대상 | 접근 방식 |
|------|------|-----------|
| **관리자 (Admin)** | 노무사/노무법인 직원 | 아이디 + 비밀번호 로그인 |
| **고객사 (Client)** | 고객사 사장님/담당자 | 접근코드(8자리) 입력 |

### 시스템 구성

```
┌─────────────────────────────────────────┐
│            웹 브라우저 (Chrome 권장)       │
├───────────────────┬─────────────────────┤
│   관리자 화면       │    고객사 화면        │
│   admin/index.html │    client/index.html │
├───────────────────┴─────────────────────┤
│        Express.js 서버 (포트 3000)        │
│        server/app.js                    │
├─────────────────────────────────────────┤
│        SQLite 데이터베이스                │
│        data/app.db                      │
└─────────────────────────────────────────┘
```

## 2. 시작하기

### 2.1 서버 실행

```bash
# 프로젝트 폴더에서
npm install    # 최초 1회: 의존성 설치
npm start      # 서버 실행 (http://localhost:3000)
```

### 2.2 관리자 로그인

1. 브라우저에서 `http://localhost:3000/admin/` 접속
2. 아이디와 비밀번호 입력
3. 👉 로그인 성공 시 **대시보드** 화면으로 이동

> **기본 관리자 계정**  
> 아이디: `admin` / 비밀번호: `admin1234!`  
> ※ 최초 로그인 후 반드시 비밀번호를 변경하세요.

### 2.3 고객사 로그인

1. 브라우저에서 `http://localhost:3000/client/` 접속
2. 관리자로부터 발급받은 **접근코드 8자리** 입력
3. 👉 로그인 성공 시 **급여현황** 화면으로 이동

## 3. 관리자 메뉴

### 3.1 대시보드

관리자 로그인 후 가장 먼저 보이는 메인 화면입니다. **전체 고객사의 현황을 한눈에** 파악할 수 있습니다.

#### 표시 정보

| 영역 | 내용 |
|------|------|
| 🔔 **계약만료 통지 배너** | D-29 이내 계약 만료 예정자 수, D-7 이내 긴급 건 → 클릭 시 해당 관리 페이지로 이동 |
| 🔔 **정규직 전환 배너** | 2년 초과 계약직 근로자(전환 의무 발생) 현황 → 클릭 시 관리 페이지로 이동 |
| 🔔 **수습 근로자 배너** | 수습 만료 임박자, 해고예고수당 대상자 현황 |
| 📝 **임시저장 알림** | 미완료된 급여 입력 건수 |
| ⚠️ **미발송 알림** | 근로계약서/급여명세서 미발송 건 |
| 💰 **급여 미입력 카드** | 고객사별 당월 급여 입력 현황 (이용중 고객사 목록) |
| 📈 **고객사 수 추이** | 월별 이용 고객사 수 변화 차트 |
| 👥 **관리 근로자 수 추이** | 월별 관리 대상 직원 수 변화 차트 |

#### 사용 방법

- 각 **배너**를 클릭하면 해당 관리 페이지로 바로 이동합니다.
- **고객사 검색**으로 특정 고객사를 빠르게 찾을 수 있습니다.
- **고객사명 클릭** 시 급여 입력 페이지로 이동합니다.
- 차트의 **조회 기간**을 6개월/12개월/24개월로 변경할 수 있습니다.

### 3.2 고객사 관리

고객사(위탁 회사)의 모든 정보를 등록·수정·관리합니다.

#### 고객사 등록

1. 좌측 메뉴에서 **고객사 관리** 클릭
2. 우측 상단 **[+ 고객사 등록]** 버튼 클릭
3. 필수 정보 입력:
   - **회사명**, **사업자등록번호**, **대표자명**
   - **업종**, **주소**, **연락처**, **이메일**
4. 급여 설정:
   - **급여지급 주기**: 월 1회 / 월 2회 선택
   - **급여일**: 급여 지급일 지정
   - **연차 산정 기준**: 입사일 기준 / 회계년도 기준
5. **[저장]** 버튼 클릭

#### 접근코드 관리

- 고객사 등록 시 **8자리 접근코드**가 자동 생성됩니다.
- 고객사 사장님께 이 코드를 전달하면 `client/` 앱에 로그인할 수 있습니다.
- 접근코드는 고객사 상세 화면에서 확인 및 재발급 가능합니다.

#### 고객사 상태

| 상태 | 의미 |
|------|------|
| **이용중** | 현재 서비스 이용 중 (급여 입력 가능) |
| **이용중지** | 일시 중지 (급여 입력 불가) |
| **임시저장** | 등록 중 임시저장 (아직 정식 등록 전) |

### 3.3 근로 계약 관리

근로계약의 생성부터 종료까지 **전 생애주기**를 관리하는 핵심 기능입니다.

#### 계약 등록 절차

1. 좌측 메뉴에서 **근로 계약 관리** 클릭
2. 상단에서 **고객사 선택**
3. **[+ 계약 등록]** 버튼 클릭
4. **직원 선택** (또는 신규 직원 등록)
5. **계약 유형** 선택:
   - 정규직 / 정규직 수습 / 계약직 / 계약직 수습 / 일용직
6. **계약 기간** 설정 (시작일 ~ 종료일)
7. **근로조건** 입력:
   - 근로시간: 1일 근로시간, 주 근로일수, 휴게시간
   - 임금: 월급, 연봉, 기본급, 시급, 주휴수당
   - 수당: 식대, 교통비, 연구수당 등 8종
   - 고정 OT: 연장/야간/휴일 근로
   - 4대보험 가입 여부
8. **[저장]** 버튼 클릭

#### 일용직 계약 특징

- **임금 지급 방법 (3분화)**: 일용직은 **일급 / 주급 / 월합산** 중 하나를 선택합니다.
  - **일급**: 지급 조건으로 `당일 지급` 또는 `근무일로부터 n일 후 지급`을 선택. 급여 산정기간은 **매일** (자동), 급여일은 근무일마다 (지급일과 관계없이 계약 시작일부터 매일 입력).
  - **주급**: 매주 지급 요일(일~토) 선택. 급여 산정기간은 **매주 [지급요일 다음날] ~ [지급요일]** (자동 표시), 급여일은 매주 해당 요일.
  - **월합산**: 급여 산정기간 기준(산정기준일, 기본 고객사 설정 · 개별 편집 가능)과 지급일(매월 n일) 설정. 실제 산정기간은 계약기간을 확인하여 자동 표시.
- **일급여 (자동계산)**: `통상일급(통상시급×8) + 통상임금 포함 수당(일급) + 통상임금 제외 고정수당(일급)` 합산 — 수정 불가(readonly), 힌트: "일 8시간 근무 기준"
- **수당 (일급 기준)**: 통상임금 포함 수당(직책·현장·기술·면허·위험·벽지)과 통상임금 제외 고정수당(식대·차량·연구·통신·체력·자기계발·도서·해외)을 일 기준으로 입력
- **주휴수당**: 계약기간(시작·종료) + 근무시간표(1일 근로시간·주 근무일수)를 모두 입력해야 자동 계산 (1주 15시간 이상 근무 기준, 계약기간 일수 비례)

#### 일용직 법적 준수 기준

> 아래 기준은 일용직 근로계약·급여 산정의 법적 준수 원칙입니다. (근로기준법 · 소득세법 · 국민연금법 · 국민건강보험법 · 고용보험법)

1. **4대 보험 공제**: 고용보험은 필수 적용, 국민연금·건강보험은 **월 8일 이상 근무** 시 적용 (월 8일 미만 근무 시 국민연금·건강보험·장기요양 공제 제외)
2. **원천징수 세금**: 소득세 및 지방소득세 — **일일 15만 원 초과금액 발생 시 공제**, 공제액 1,000원 미만은 **소액부징수** (미부과)
3. **연장/야간/휴일근로 가산 기준**: 통상시급이 아닌 **일급여 기준**으로 가산. **5인 이상 사업장만 가산** (5인 미만 사업장은 가산 없음 = ×1.0)
4. **비과세 수당 월 20만 원 합산**: 비과세 적용 수당(식대·차량·연구·보육 등)은 **매월 합산 금액**을 산출하여 **월 20만 원까지 비과세**. 일급제·주급제인 경우 **이전 계약들까지 조회**해 매월 1일부터의 해당 수당 일급을 합산한 금액이 한도를 넘기 전까지 비과세 처리
5. **해고예고**: **3개월 이상 계속 근무**한 일용직을 해고할 때는 **30일 전에 예고**해야 하며, 예고하지 않으면 **30일분의 해고예고수당** 지급 대상 (근로기준법 제26조)
6. **회사 귀책 결근 시 주휴·휴업**: 근태관리대장에서 결근 사유가 **회사사정(사용자의 귀책사유)**으로 인한 것이면, 나머지 출근일만 개근했다면 **주휴수당은 정상 지급**합니다. **5인 이상 사업장**이라면 당일 쉰 것에 대한 **휴업수당 70%**도 별도 발생 (예: 비·자재 부족·공사 물량 없음으로 "오늘은 쉬라"는 경우)
7. **법정 휴일·근로자의 날과 주휴**: 계약기간에 **법정 휴일이나 근로자의 날**이 끼어 있어 근무시간표에 근무 요일로 기재되어 있더라도, **나머지 약속된 날에 모두 출근했다면 주휴수당을 지급**합니다.
8. **사전승인 무급휴가 → 비례 주휴**: 사전에 '휴가'를 승인받아 결근한 경우(예: 사전 승인 무급휴가, 예비군 훈련, 경조사 등) — 고용노동부 기준에 따라 **결근한 날을 제외한 나머지 소정근로일수·근로시간에 비례**하여 주휴수당을 계산해 지급합니다. (근태관리대장에 사전승인 무급휴가 여부를 기록할 수 있어야 함)
9. **일용직 연차 판별**: **1주 소정근로시간(15시간 기준)**과 **실제 계속근로기간(1달 미만 또는 1년 이상)**에 따라 판별 방식이 달라집니다.
   - **주 15시간 미만 (초단시간)**: 연차휴가 규정 **법적 미적용**
   - **주 15시간 이상**:
     - ① 입사 1년 미만: 1달 동안 약속된 근로일(소정근로일)을 **개근**하면 다음 달에 **1일 유급휴가** 발생 (1년 미만 최대 11일)
     - ② 1년 이상 계속 근로: 계약 갱신 등을 통해 **1년간 출근율 80% 이상**이면 다음 연도에 **15일 연차** 발생

#### 계약 상태

| 상태 | 설명 |
|------|------|
| **계약예정** | 미래 시작일이 도래하지 않은 계약 (시작일 당일 자동 활성화) |
| **활성** | 현재 유효한 계약 |
| **만료** | 계약 종료일이 지난 계약 |
| **해지** | 중도 해지된 계약 |
| **파기** | 무효화된 계약 |

#### 계약 관련 작업

- **수정**: 활성 계약 내용 변경
- **갱신**: 만료 계약 연장
- **해지**: 계약 중도 종료 (사유 기록)
- **파기**: 계약 무효화
- **수정재발행(amend)**: 기존 계약을 수정한 새 버전 발행
- **계약서 출력**: 인쇄 / PDF / DOCX 다운로드

### 3.4 계약서 발송 관리

작성된 근로계약서를 고객사/근로자에게 발송하고 이력을 관리합니다.

#### 발송 절차

1. 좌측 메뉴에서 **계약서 발송 관리** 클릭
2. **고객사 선택**
3. **입사월 선택** → 미발송 계약서 목록 확인
4. 발송 방식 선택:
   - 📱 **카카오 알림톡**: PDF 첨부 발송
   - 📧 **이메일**: PDF 첨부 발송
   - ✋ **수동 배부**: 출력 교부 (직접 전달)
5. 개별 또는 **일괄 발송**

> 💡 **일괄 발송**: 미발송 전체 건을 한 번에 알림톡으로 발송할 수 있습니다.

### 3.5 계약만료 통지 관리

**법적 의무사항**인 계약만료 통지를 체계적으로 관리합니다.  
계약직 근로자의 계약 만료 **29일 전**부터 통지 대상이 됩니다.

#### 긴급도 구분

| 구분 | 기준 | 배지 |
|------|------|------|
| 🔴 **긴급** | D-0 ~ D-7 | 빨간색 |
| 🟠 **임박** | D-8 ~ D-14 | 주황색 |
| 🟡 **일반** | D-15 ~ D-29 | 노란색 |

#### 통지 발송

1. 대상 목록에서 발송할 직원 선택
2. 발송 방식 선택 (알림톡 / 이메일)
3. **[발송]** 클릭
4. 발송 이력 탭에서 결과 확인

> ⚠️ 이미 통지 이력이 있는 계약은 중복 발송되지 않도록 자동 제외됩니다.

### 3.6 정규직 전환 관리

**기간제법 제4조**에 따라 계약직 근로자를 2년 초과 사용 시 정규직 전환 의무가 발생합니다.

#### 대상자 분류

| 상태 | 기준 | 조치 |
|------|------|------|
| 🔴 **전환 의무 발생** | 누적 2년 초과 | 즉시 전환 필요 |
| 🟠 **임박** | 1년 9개월 ~ 2년 | 90일 이내 전환 준비 |
| 🟡 **주의** | 1년 6개월 ~ 1년 9개월 | 180일 이내 사전 검토 |

> **누적 기간 계산**: 동일 직원의 모든 계약직·계약직 수습 계약 기간을 합산합니다.

### 3.7 수습 근로자 관리

수습기간 중인 근로자를 모니터링하고, 수습 종료 시 처리 결과를 기록합니다.

#### 주요 지표

| 지표 | 설명 |
|------|------|
| **전체 수습자** | 현재 수습 중인 전체 근로자 수 |
| **서면통지 대상** | 수습 3개월 초과 + 만료 30일 이상 → 해고 시 30일 전 서면통지 의무 |
| **해고예고수당 대상** | 수습 3개월 초과 + 만료 30일 미만 → 해고 시 30일치 수당 지급 의무 |

#### 처리 옵션

- ✅ **채용 확정**: 정식 채용 전환 (정규 계약서 자동 생성)
- ❌ **채용 취소**
- 🚫 **조기 해고**
- ⏳ **수습 연장**

### 3.8 급여 입력

월별 직원 급여를 계산하고 입력하는 기능입니다.

#### 입력 절차

1. 좌측 메뉴에서 **급여 입력** 클릭
2. **고객사 선택** (칩 목록에서 검색)
3. **급여지급 년월 선택** (예: 2026년 6월)
4. 직원 목록에서 **급여 입력할 직원 선택**
5. 급여 상세 입력:
   - **좌측**: 계약 조건 요약 카드
   - **우측**: 급여 입력 폼
     - 기본급, 주휴수당
     - 각종 수당 (식대, 교통비 등)
     - 연장/야간/휴일 근로수당
     - 4대보험 공제
     - 소득세, 지방소득세
6. **하단 합계 확인**: 지급총액 / 공제합계 / 실수령액
7. **[저장]** 클릭

#### 부가 기능

- **임시저장**: 입력 중간에 임시저장 가능 (`is_draft`). 추후 이어서 입력 가능
- **전체 임시저장 목록**: 최상단 배너에서 모든 임시저장 건 확인
- **엑셀 업로드**: 전직원 임금대장 엑셀 파일을 드래그앤드롭으로 일괄 업로드
- **전월 임금대장 다운로드**: 지난달 데이터를 엑셀로 다운로드
- **일용직 즉시 발급**: 일용직 급여 확정 저장 시 지급방법(일급/주급/월합산)에 따른 지급일 기준으로 급여명세서가 즉시 생성되고, 고객사 인앱 알림 + 근로자에게 다운로드 경로 안내 메시지(SMS)가 자동 발송됩니다.
- **일용직 급여 처리 할일**: 대시보드 할일 목록에 지급 예정일이 도래한 일용직 근로자의 **급여 입력/명세서 발송 대상**이 표시되며, 클릭 시 급여 입력 페이지로 이동합니다.
- **연속 계약 주휴 합산**: 일용직에서 이전 계약의 마지막주와 현 계약의 첫주가 **같은 주**일 때, 이전 계약 마지막주 근로시간 + 현 계약 첫주 근로시간이 **15시간 이상**이고 두 주 근로일수를 **모두 개근**하면 해당 주 주휴수당이 지급됩니다. 이전 산정기간(이전 월) 출근 여부는 근태 관리대장을 조회해 확인하며, 합산된 이전 계약 마지막주 근로시간·근로일수·개근 여부가 힌트로 표시됩니다.

### 3.13 연차 관리

직원별 연차휴가 발생·사용·잔여 현황을 관리합니다.

#### 주요 기능

1. **고객사 선택** → **기준년도 선택**
2. 직원별 연차 현황 테이블:
   - 총 발생 연차, 사용 연차, 잔여 연차
   - 잔여 연차 수당 추계액
3. **[📋 관리]** 버튼 → **월별 사용 현황 입력 모달**
   - 1월~12월: 사용일자, 사용일수(0.5일 단위), 비고
   - 실시간 합계·잔여 연차 자동 계산
4. **사용촉진 발송**: 개별 직원에게 연차 사용촉진 메시지 발송

#### 연차 산정 기준

- **입사일 기준**: 입사일로부터 1년 단위
- **회계년도 기준**: 1월 1일 ~ 12월 31일 (고객사 설정에 따름)

- 발송 방식별 필터: 카카오 알림톡, 이메일, 유선 안내
- 통계: 전체 건수, 이번달 건수

### 3.15 퇴직급여 관리

퇴직금 추계 및 지급 이력을 관리합니다.

#### 탭 1: 근로자별 퇴직급여 추계

- 오늘 기준 **예상 퇴직금** 자동 계산
- 직원별: 재직기간, 평균 통상임금, 퇴직금 추계액
- 제외 대상: 1년 미만 재직자, 일용직
- 퇴직금 산식: **(평균임금 × 30일) × (총 재직일수 ÷ 365)**

#### 탭 2: 지급 발생 이력

- 퇴사 처리된 근로자의 퇴직금 정산내역
- 정산내역서: 엑셀/PDF 다운로드, 알림톡/이메일 발송

### 3.16 년도별 산정기준

급여 계산에 필요한 **기준 정보**를 연도별로 관리합니다.

#### 탭 1: 4대보험 요율표

- 국민연금, 건강보험, 장기요양보험, 고용보험 요율
- 현재 연도 적용 구간 강조 표시

#### 탭 2: 최저임금표

- 연도별 최저시급, 최저월급 (현재 연도 강조)

#### 탭 3: 과세 기준 (간이세액표)

- 부양가족 수별(1인~7인) 월급여 구간별 소득세
- 지방소득세 = 소득세 × 10%

> 💡 **년도별 산정기준 업데이트 알림**: 새 연도 기준이 업데이트되면 대시보드에 배너로 알립니다.

### 3.17 관리자 계정 관리

- **비밀번호(password)**: 로그인 비밀번호

> ⚠️ 모든 발송·작업 이력은 **username** 기준으로 저장되므로, 표시이름을 변경해도 과거 이력에 자동 반영됩니다.

### 3.18 알림 발송 이력

#### 알림 유형 (22종)

- **계약 관련**: 신규 계약, 계약 수정, 계약 파기, 수정재발행, 계약 해지, 계약 갱신 등

- **기타**: 퇴직급여 지급, 계약만료 통지, 정규직 전환 통지, 연차 사용촉진, 중요공지

#### 주요 기능

- 알림 유형별 **필터링**
- **예약 발송** 건 별도 관리 (즉시발송/취소 가능)
- **상세 보기**: 알림 전체 내용 확인

### 3.19 중요공지 관리

## 5. 주요 업무 흐름

### 5.1 신규 고객사 온보딩

```
① 고객사 등록 (고객사 관리)
  └→ 회사 정보 입력, 접근코드 자동 발급
       ↓
② 직원 등록 (근로 계약 관리)
  └→ 직원별 근로계약 작성
       ↓
③ 계약서 발송 (계약서 발송 관리)
  └→ 카카오 알림톡/이메일로 계약서 발송
       ↓
④ 접근코드 전달 (고객사에 안내)
  └→ 고객사 사장님께 client/ 접속 방법 안내
```

### 5.2 월 급여 처리

```
① 급여 입력 (급여 입력 메뉴)
  └→ 고객사 선택 → 직원별 급여 입력
       ↓
② 급여 명세서 확인 (급여 명세서 조회)
  └→ 입력 내용 최종 검토
       ↓
③ 급여 명세서 발송 (급여 명세서 발송 관리)
  └→ 카카오 알림톡/이메일로 직원별 명세서 발송
```

### 5.3 계약만료 대응

```
① 대시보드에서 계약만료 배너 확인
  └→ D-29 이내 만료 예정자 확인
       ↓
② 계약만료 통지 발송 (계약만료 통지 관리)
  └→ 알림톡/이메일로 통지
       ↓
③ 후속 조치
  ├→ 계약 갱신 (근로 계약 관리)
  ├→ 정규직 전환 (해당 시)
  └→ 퇴사 처리 및 퇴직금 정산
```

### 5.4 정규직 전환 처리

```
① 대시보드/정규직 전환 관리에서 대상자 확인
  └→ 2년 초과 계약직 근로자
       ↓
② 통지 발송 (정규직 전환 관리)
  └→ 고객사에 전환 의무 안내
       ↓
③ 계약 전환 (근로 계약 관리)
  └→ 계약직 → 정규직 계약서 작성
```

## 6. FAQ / 문제 해결

### Q. 서버가 실행되지 않아요.

```bash
# 의존성 패키지가 설치되어 있는지 확인
npm install

# 포트 3000이 이미 사용 중인지 확인
netstat -ano | findstr ":3000"

# 다른 프로그램이 3000번 포트를 사용 중이면 종료 후 재시작
npm start
```

### Q. 로그인이 안 돼요.

- 아이디/비밀번호가 올바른지 확인하세요.
- `admin_accounts` 테이블에 계정이 등록되어 있는지 확인하세요.
- 서버가 정상 실행 중인지 확인하세요.

### Q. 데이터가 저장되지 않아요.

- `data/app.db` 파일이 존재하는지 확인하세요.
- 파일 쓰기 권한이 있는지 확인하세요.
- 브라우저 콘솔(F12)에서 오류 메시지를 확인하세요.

### Q. 고객사 앱에서 데이터가 보이지 않아요.

- 접근코드가 올바른지 확인하세요.
- 해당 고객사의 계약/급여 데이터가 관리자 페이지에 입력되어 있는지 확인하세요.
- 고객사 상태가 "이용중"인지 확인하세요.

### Q. 차트가 표시되지 않아요.

- 인터넷 연결을 확인하세요 (Chart.js CDN 로드 필요).
- 브라우저 콘솔(F12)에서 JavaScript 오류를 확인하세요.
- Chrome 브라우저 사용을 권장합니다.

### Q. 엑셀 다운로드/업로드가 안 돼요.

- SheetJS 라이브러리 로드 상태를 확인하세요.
- 업로드 시 엑셀 파일 형식(.xlsx)이 올바른지 확인하세요.
