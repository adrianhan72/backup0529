## 2. 실제 미구현 항목 (R9)

### R9: 국가 지원금 회사 부담 구분 표시

**현황**: 산재/육아휴직/출산휴가 등은 급여 계산에서 0원 처리(차감 제외)되지만, 급여 명세서/PDF 어디에도 "국가 지원금" 개념이 표시되지 않음. 고객사 사장님이 "회사가 지급한 금액"과 "정부가 지급한 금액"을 구분해서 볼 수 없음.

**개선 방안**:

1. **DB**: `payrolls` 테이블에 `government_subsidy REAL DEFAULT 0` 컬럼 추가 (참고용)
2. **계산**: `calcPI()`에서 `_maternityPay`, `_layoffPay` 등의 회사 부담분과 국가 지원 추정액을 구분 집계
3. **명세서 UI**: 급여명세서 하단에 "국가 지원금 (참고)" 행 추가
   - 출산휴가: `min(통상임금, 2,200,000원)` × 해당일수 (고용보험 지급 추정)
   - 육아휴직: 통상임금 100% (고용보험 지급)
   - 산재: 통상임금 100% (근로복지공단 지급)
4. **PDF**: 명세서 PDF에도 동일 정보 포함

**영향**: DB 스키마 + `payroll-input-main.js` (calcPI) + `payslip-send.html` (명세서 UI) + PDF 템플릿

## 6. 추가 검토 사항

### 6.1 대기업 지원
현재 시스템은 **우선지원대상기업**(중소기업) 기준만 구현되어 있습니다. 출산휴가에서 대기업은 통상임금 100%를 회사가 직접 부담하지만, 현 코드는 우선지원대상기업 기준(220만원 초과분만 회사 부담)으로 하드코딩되어 있습니다.

- `companies` 테이블에 `company_size` 컬럼 (`priority_support` / `large` / `general`) 추가 검토
- `_maternityPay` 계산에서 대기업 분기 추가 필요

### 6.2 평균임금 산출 안정성
`_calcDailyAverageWage()` 함수는 휴업수당 계산에 사용됩니다. 신규 입사자의 경우 평균임금 산출이 불가능하여 통상임금 70%로 폴백하는데, 이 동작이 모든 케이스에서 적절한지 추가 검증이 필요합니다.
