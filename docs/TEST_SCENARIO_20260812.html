Part B: 근로계약 생애주기 (5건)

단계액션기대 결과
1고정오 계약 → "수정" 버튼 클릭수정 모달, 기존 계약 데이터 로드

5계약 목록 확인기존 계약 상태 "파기", 신규 계약 "활성"

B2. 재계약 — 만료된 일용직 → 새 계약

단계액션기대 결과

2계약기간, 근무조건 확인 후 등록신규 계약 생성, 이전 계약 만료 상태 유지
3급여입력 진입신규 계약 기준 급여만 표시, 만료 계약 분리

B3. 갱신 — 수습→본계약 전환

단계액션기대 결과
1박수습 계약 → "갱신" 버튼갱신 모달, 수습 조건(90%, 3개월) 표시
2본계약 조건으로 갱신 확정수습 90% → 100% 전환, 기본급 인상
3갱신 전후 급여 비교갱신 전: 12,000×0.9=10,800원 기준, 갱신 후: 12,000원 기준

B4. 해지 — 계약 해지 처리

단계액션기대 결과

해지예정일까지 급여산정기간 자동설정
3급여입력 진입급여산정기간 종료일 = 2026-08-20

B5. 해지취소 — 원상복귀

단계액션기대 결과
1정무급여(terminated) 계약 → 해지취소해지 상태 해제, 원래 계약조건 복원

Part C: 임시저장 + 유효성 검증 (3건)

C1. 신규직원 임시저장 → 이어쓰기 → 등록

단계액션기대 결과
1고객사 선택 → "신규 등록"신규 직원 입력 폼

3임시저장 목록 → "이어서 작성"이전 입력값 복원
4필수 필드 채우지 않고 "등록" 시도❌ 유효성 오류: 사원번호, 주민번호, 입사일, 휴대전화 등 하이라이트

단계액션기대 결과

2시급, 근무시간표 등 확인 후 "등록"✅ draft→active 전환, 직원 정보 승계

C3. 필수 필드 누락 검증

단계액션기대 결과
1신규 등록 → 시급 미입력 → "등록"❌ "통상시급" 하이라이트 + 배너
2근무시간표 미설정 → "등록"❌ "근무시간표" 하이라이트
3사원번호 중복 입력 → "등록"❌ "사원번호 중복" 오류
