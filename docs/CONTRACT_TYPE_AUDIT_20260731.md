**급여 산정**:

**고지 발송**:

### 2.2 정규직 수습 (REGULAR_PROBATION)

**계약 요건**:
- 수습기간: `probation_months` 필수, `_calcProbationEndDate()`로 종료일 자동계산
- 수습 임금: `probation_amt`(직접) 또는 `월약정 × probation_pct%`
- 최저임금: **90%** 허용 (최저임금법 §5②) ✅

**급여 산정**:
- 수습 월 약정임금: `probation_amt` 우선, 없으면 `monthly_salary_agreed × probation_pct/100`
- ⚠️ `calcPI()`에서 수습 임금 감액 **자동 미적용** — 기본급은 여전히 `base_salary` 값 사용
- 수습 만료 초과 월: 케이스①(전체 초과)·②(분할) 패널로 차단 ✅

**고지 발송**:
- 🔴 **수습→정규직 전환 자동통지 부재**: 수습 종료 시 채용확정 계약 자동생성은 되나, 사용자/근로자 대상 알림 없음
- ⚠️ **730일 검사 과잉 포함**: REGULAR_PROBATION이 `TARGET_TYPES`에 포함됨 → 정규직 수습은 무기한 계약이므로 기간제법 2년 제한 대상 아님

**법적 근거**:
- 기간제법 제4조: "기간의 정함이 없는 근로자"에겐 적용되지 않음
- 정규직 수습은 기간의 정함이 없는 계약 + 수습 조건 → 730일 규제 대상 아님

**평가: 🟡 2건 이슈**

### 2.5 일용직 (DAILY)

**계약 요건**:
- 일급여: `daily_wage` 필수 ✅
- 계약종료일: 필수 ✅
- `work_days_per_week`: 저장 시 `0` 설정
- 계약서: `일 용 근 로 계 약 서` (별도 양식) + 일용직 안내문 ✅

**급여 산정**:
- 기본급: `daily_wage × work_days` ✅
- ✅ **주휴수당 계산**: `calcWeeklyHolidayPay()` 주 단위 완전근무 검증 (근로기준법 제55조)
  - 1주 15시간 이상 + 개근 시 주휴수당 발생, 무급 휴가(무단·무급병가·생리·가족돌봄·유급병가) 있는 주는 미발생
  - **연속 계약 합산 규정**: 이전 계약 마지막주와 현 계약 첫주가 같은 주일 때, 이전 계약 마지막주 + 현 계약 첫주 근로시간 합산 15시간 이상 + 모두 개근 시 해당 주 주휴 인정 (이전 산정기간 출근 여부는 근태 관리대장 조회)
- ⚠️ **연차 미배제**: `_AL_EXCLUDED`에 `CONTRACT_TYPE.DAILY` 누락
  - `work_days_per_week=0`으로 인해 주15시간 미만 → 암묵적 연차 제외
  - 의도된 동작이나 코드 명확성 부족

**계약서 임금 (일용직)**:
- 급여일: `YYYY-MM-DD` 날짜로 지정 (당일·주급·월급 모두 가능)
- 일급여(자동계산, readonly): `통상일급(통상시급×8) + 통상임금 포함 수당(일급) + 통상임금 제외 고정수당(일급)` 합산
- 통상임금 포함·제외 고정수당 모두 일(일급) 기준 입력

**고지 발송**:
- 계약만료 29일 전 통지: ✅

**평가: ✅ 시정 완료 (일용직 주휴수당 계산 + 연속 계약 합산 규정 적용)**

## 3. 발견된 이슈

### 🔴 시정 필요

#### #1: 일용직 주휴수당 미계산
- **파일**: `payroll-input-main.js:2967`
- **현재**: `if(piContract && piContract.contract_type !== CONTRACT_TYPE.DAILY)`
- **법적 근거**: 근로기준법 제55조 (모든 근로자 적용)
- **영향**: 1주 15시간 이상 개근한 일용직 근로자의 주휴수당 누락 → 임금체불 위험
- **수정안**: DAILY 타입 제외 조건 제거하고 `calcWeeklyHolidayPay()` 내부에서 `work_days_per_week`와 `work_hours_per_day`로 판정

### 🟡 권고 사항

#### #4: 수습 미채용(해고) 시 서면통지 안내 (근로기준법 제27조)

**법적 요건**: 해고사유와 시기를 **서면으로** 근로자에게 통지해야 함. 이메일·문자메시지로는 효력 없음 → 사업주가 **직접 종이 문서로 교부**해야 하는 의무.

**현 시스템 구현**:
- ✅ `execProbDismiss()` 시 `dismissal_notice_pay`(해고예고수당) 자동 계산
- ✅ 서버 CRON: 수습만료 30일 전 `PROBATION_EXPIRY_001` 알림톡으로 고객사에 사전 안내
- ✅ 대시보드: "서면통지 대상 X명" / "해고예고수당 대상 Y명" 실시간 집계
- ✅ `probation-mgmt` 페이지: 채용확정·채용취소·조기해고·수습연장 4개 액션 지원
- 🟡 **권고**: 미채용 결정 시 고객사앱 인앱 알림으로 "해고사유서면통지서를 작성하여 근로자에게 직접 교부하세요" 안내 추가 (서비스가 직접 발송하지 않음)
