# 노무사 급여 관리 시스템 v2.33.0

## 프로젝트 개요
노무사가 고객사 사장님들을 위해 제공하는 **급여 관리 서비스** 플랫폼입니다.
- **관리자용 사이트** (`admin/index.html`): 노무사 전용 통합 급여·계약 관리
- **고객사 전용 앱** (`client/index.html`): 고객사 사장님이 접근코드로 급여통계·명세서 조회 (v2.13.0 개편)

---

## 🚀 시작하기

### 1. 메인 페이지 접속
- **index.html** 을 열면 랜딩 페이지가 나타납니다
- "관리자 사이트" 또는 "고객사 앱" 버튼을 클릭하여 원하는 페이지로 이동하세요

### 2. 관리자 사이트 (`admin/index.html`)
- **노무사 전용** 관리 페이지
- 페이지를 열면 자동으로 데이터를 로드합니다
- 고객사, 직원, 계약, 급여 정보를 관리할 수 있습니다
- **콘솔 로그 확인**: F12를 눌러 개발자 도구를 열면 데이터 로드 상태를 확인할 수 있습니다

### 3. 고객사 앱 (`client/index.html`) — v2.13.0 개편
- **고객사 사장님 전용** 급여 조회 페이지
- 로그인 화면에서 **접근 코드**를 입력해야 합니다
- 아래 4개 탭으로 구성:
  - **급여현황** (메인): 직원 현황·당월 급여지급액·분포차트·파이차트·1년 추이·근로계약 목록
  - **명세서**: 고용형태별 탭(전체/정규직/계약직 등)으로 해당 월 직원 전체 명세서 목록 조회, 카드 탭 시 상세 모달 표시
  - **사용료**: 서비스 이용료 납부 현황
  - **우리회사**: 회사 기본정보·연락처·급여정보·고용형태별 인원·근로계약 현황
- 아래 테스트 코드를 사용하세요
