계약 상태 플래그 설명
계약유효
현재 근무 중인 활성 계약입니다. 계약 시작일이 오늘 이전이며 아직 만료·해지되지 않은 상태입니다.
갱신예정
계약 시작일이 오늘 이후인 아직 시작되지 않은 계약입니다. 시작일이 도래하면 자동으로 계약유효로 표시됩니다. 배너에서 수정 또는 파기가 가능합니다.
계약예정
재계약 또는 신규 계약 등록 시 시작일이 미래인 경우 부여됩니다. 갱신예정과 동일하게 시작일 전까지 수정·파기할 수 있습니다.
해지예정
정규직 직원의 퇴사예정일이 설정된 상태입니다. 퇴사예정일이 되면 자동으로 해지 처리됩니다. 배너에서 퇴사예정일을 수정하거나 해지 취소로 활성 상태로 복귀할 수 있습니다.
해지
계약이 조기 종료된 상태입니다. 계약 종료일을 앞당기거나 퇴사예정일이 도래하면 해지로 전환됩니다. 해지된 계약은 재계약 버튼으로 새 계약을 생성할 수 있습니다.
만료
계약 기간이 정상적으로 종료된 상태입니다. 계약직·일용직의 계약 종료일 도래 또는 갱신 처리 시 기존 계약에 부여됩니다. 만료된 계약은 재계약 버튼으로 새 계약을 생성할 수 있습니다.
파기
시작 전 취소된 계약입니다. 갱신예정·계약예정 상태에서 배너의 파기 버튼을 누르면 전환됩니다. 계약이 성립되지 않은 것으로 기록됩니다.
임시저장
작성 중 임시저장된 계약서입니다. 등록이 완료되지 않은 상태로, 목록에서 임시저장 이어쓰기 버튼으로 계속 작성할 수 있습니다.
계약 유형별 관리 방법
정규직 / 정규직 수습
만료일 없이 무기한 계약. 퇴사 시 퇴사예정 설정 버튼으로 퇴사예정일을 지정합니다. 계약 기간을 연장할 경우 갱신 버튼을 사용해 기존 계약을 만료 처리하고 새 계약을 생성합니다.
계약직 / 계약직 수습
종료일이 있는 기간제 계약. 종료일이 지나면 자동으로 만료로 표시됩니다. 계속 고용 시 재계약 버튼으로 새 계약을 등록합니다. 종료일을 앞당기는 수정은 해지로 처리됩니다.
일용직
단기 계약. 건별로 계약서를 등록하며 주휴수당·연봉 계산 없이 일급여 기준으로 관리됩니다. 반복 고용 시 매번 새 계약서를 추가합니다.
주요 액션 가이드
📌 정규직 연장 (갱신)
계약유효 계약 조회 → 갱신 버튼 클릭 → 기존 종료일·새 시작일 입력 → 갱신 확정
기존 계약은 만료로 전환되고 새 계약이 자동 생성됩니다.
📌 정규직 퇴사 처리
계약유효 계약 조회 → 퇴사예정 설정 → 퇴사예정일 입력 → 해지예정 → 당일 도래 시 → 해지
📌 계약직 재계약
만료·해지 계약 조회 → 재계약 버튼 → 새 계약 조건 입력 → 등록
📌 예정 계약 수정·파기
갱신예정·계약예정 계약 조회 → 상단 배너의 수정 또는 파기 버튼
수정 시 날짜·근무조건·급여 등 모든 항목을 변경할 수 있습니다. 파기 시 계약 성립 취소로 기록됩니다.
⚠ 주의사항
• 계약 종료일을 앞당기는 수정은 해지로 처리됩니다. 종료일 연장은 갱신 버튼을 사용하세요.
• 만료·해지·파기된 계약은 삭제되지 않으며 기록 보존 목적으로 유지됩니다.
• 동일 직원에게 여러 계약서가 있을 수 있으며, 가장 최근 유효 계약이 급여 계산에 사용됩니다.
